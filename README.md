## 为什么要用 ChatGPT / Codex

ChatGPT 是 OpenAI 推出的通用 AI 助手，擅长对话问答、文案写作、翻译、数据分析等场景；Codex 则是 OpenAI 专为开发者打造的 AI 编程代理，能理解代码仓库、自动修复 Bug、编写测试、提交 PR。

对于国内开发者来说，这两个工具能极大提升效率，但由于网络限制，直接访问会遇到障碍。本教程将完整讲解从零开始的使用流程。

| 工具           | 定位                         | 适合人群    |
| ------------ | -------------------------- | ------- |
| ChatGPT（免费版） | 通用 AI 对话                   | 所有人     |
| ChatGPT Plus | 增强对话 + GPT-6 + 部分高级功能      | 重度用户    |
| Codex（桌面端）   | AI 编程代理，集成在 ChatGPT 桌面客户端中 | 开发者     |
| Codex CLI    | 本地终端编程代理，开源                | 开发者（进阶） |

## 第四步：使用 Codex（编程利器）

Codex 是 OpenAI 推出的 AI 编程代理，能够理解整个代码仓库、自动执行编程任务。有两种使用方式：

### 5.1 方式一：ChatGPT 桌面端使用 Codex

如果你已升级 ChatGPT Plus / Pro / Team，推荐使用 ChatGPT 桌面客户端，体验比网页端更流畅，支持系统级快捷键唤起，还能与本地 IDE 联动：

1. **下载桌面客户端**：访问 `https://chatgpt.com/zh-Hans-CN/codex/` 下载对应版本（支持 macOS 和 Windows），也可在 Mac App Store / Microsoft Store 搜索「ChatGPT」安装。
2. **登录 Plus 账号**：打开客户端，使用你的 ChatGPT Plus / Pro / Team 账号登录。
3. **选择 Codex**：在左侧导航中点击「Codex」标签，进入 Codex 工作台。
4. **关联 GitHub 仓库**：按提示连接你的 GitHub 账号，选择需要处理的代码仓库。
5. **下达任务**：用自然语言描述你需要的任务，例如「修复登录页面的样式 bug」「为 utils.js 添加单元测试」「重构用户认证模块」。
6. **审查与合并**：Codex 完成任务后会生成代码变更，你可以在桌面端直接查看 Diff，审查后决定是否合并到主分支。

> 💡 **桌面端优势**：支持全局快捷键（macOS 为 `Option + Space`）随时唤起；可搭配 IDE 插件在编辑器内直接调用；任务完成后有系统通知，无需盯着页面等待。

### 5.2 方式二：安装 Codex CLI（本地终端使用）

Codex CLI 是 OpenAI 开源的命令行工具，适合喜欢在终端工作的开发者：

```bash
# 全局安装 Codex CLI（需要 Node.js 22+）
npm install -g @openai/codex

# 配置 API Key
export OPENAI_API_KEY="你的API密钥"

# 在项目目录中启动 Codex
cd your-project
codex
```

### 5.3 获取 OpenAI API Key(可选)

1. **访问 OpenAI Platform**：打开 `https://platform.openai.com`，使用你的 ChatGPT 账号登录。
2. **充值余额**：进入 Billing 页面，使用虚拟信用卡充值（最低充值 $5 即可开始使用）。
3. **创建 API Key**：进入 API Keys 页面，点击「Create new secret key」，复制生成的密钥（**只显示一次，务必保存好**）。
4. **配置环境变量**：将 API Key 配置为环境变量 `OPENAI_API_KEY`，Codex CLI 会自动读取。

> 💡 **费用说明**：Codex CLI 按 API 调用 token 计费，日常编程任务每月费用通常在 $2-10 之间，比 ChatGPT Plus 订阅更灵活。如果重度使用，ChatGPT Plus 的 Codex 桌面端更划算。

### 5.4 Codex 使用技巧

- **描述清晰**：任务描述越具体，Codex 的输出质量越高，例如「在 src/auth/login.js 中添加表单参数校验，用户名为空时提示错误」
- **分步执行**：复杂任务拆成多个小任务，逐步让 Codex 完成
- **审查代码**：Codex 生成的代码务必人工审查后再合并，AI 可能引入潜在问题
- **利用上下文**：Codex 会读取整个仓库上下文，确保项目结构和依赖清晰

## 常见问题与排坑

### Q1：访问 ChatGPT 提示 "Access denied" 或 "Not available in your country"？

说明你的代理节点 IP 被 OpenAI 识别为不支持地区。尝试切换代理节点（推荐美国节点），或清除浏览器缓存后重试。使用[西瓜加速](https://www.xiguajiasu8.com/?path=register\&code=NkHYNhHc)的美国节点通常不会有此问题。

### Q2：注册时提示手机号不支持？

OpenAI 不支持中国大陆手机号（+86）。必须使用海外手机号或接码平台的虚拟号码完成验证。

### Q3：ChatGPT 回答突然变慢或中断？

通常是代理网络不稳定导致。检查代理连接状态，切换延迟更低的节点。西瓜加速提供多条线路，选择延迟最低的即可。

### Q4：Codex 一直显示"正在重新连接"

```shell
cat > ~/.codex/.env << 'EOF'
HTTP_PROXY=http://127.0.0.1:7890
HTTPS_PROXY=http://127.0.0.1:7890
NO_PROXY=localhost,127.0.0.1
EOF

chmod 600 ~/.codex/.env
```
三个要点：
1. 端口换成你自己的代理端口
2. NO_PROXY 别省。 Codex 登录走本地回调 localhost:1455/auth/callback，不排除本地地址的话，可能被代理劫持导致登录失败。
3. 不需要写 ALL_PROXY。 HTTP_PROXY / HTTPS_PROXY 已覆盖全部 http/https 流量（HTTPS 走 CONNECT 隧道），多写一行只是多一个出错点。
